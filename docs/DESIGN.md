# 공시 분석 모바일 사이트 설계 문서 v1.0

## 1. 목적
기업의 공시·재무·뉴스를 한 화면에 모아 **위험도(안정성)를 점수와 색으로 한눈에** 보여 주고,
충격 상황(매출 감소·부채 증가·금리 상승)을 가정해 **점수가 어떻게 변하는지 시뮬레이션**한다.
참고용 도구이며 투자 권유가 아니다.

## 2. 사용 서비스 (전부 무료)
| 용도 | 서비스 | 비고 |
|---|---|---|
| 공시·기업개황·재무 | 오픈DART API | 무료 인증키 필요 (없으면 데모 데이터로 동작) |
| 뉴스 | 구글 뉴스 RSS | 키 불필요 |
| 배포 | Vercel 무료(Hobby) | 비상업용 |

## 3. 화면 구성 (모바일 우선, 하단 탭 4개)
1. 홈: 검색창, 관심 기업, 최근 본 기업
2. 요약: 위험도 게이지 + 레이더 + 핵심 신호
3. 공시·뉴스: 최근 공시(위험 태그), 최근 뉴스
4. 시뮬레이션: 슬라이더 3개로 점수 변화 확인

## 4. 위험도 점수 (0~100, 높을수록 안정)
| 영역 | 가중치 | 보는 것 |
|---|---|---|
| 재무 안정성 | 40 | 부채비율, 유동비율 |
| 수익성 | 25 | 영업이익률, 이자보상배율 |
| 공시 신호 | 20 | 최근 공시의 위험 키워드 개수·강도 |
| 뉴스 분위기 | 15 | 최근 뉴스 제목의 부정/긍정 비율 |

등급: 80+ 안정 / 60~79 보통 / 40~59 주의 / 40 미만 위험

## 5. 시뮬레이션
- 매출 변화(-50%~+20%), 부채 증가(0~+100%), 금리 상승(0~+5%p)
- 영업이익, 부채비율, 이자보상배율을 다시 계산해 점수 재산출

## 6. 데이터 흐름
브라우저 → `/api/*` (Next.js 서버) → DART / 구글 뉴스 RSS
키가 없거나 호출 실패 시 → 데모 데이터로 대체하고 화면에 "데모 데이터" 표시

## 7. 15단계
1 설계 → 2 프로젝트 → 3 레이아웃 → 4 타입 → 5 공시 API → 6 검색 → 7 기업 상세 → 8 재무 지표 → 9 뉴스 → 10 공시 분류 → 11 점수 엔진 → 12 시뮬레이션 → 13 대시보드 → 14 관심 기업·PWA → 15 검증·배포
